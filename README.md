# 📊 Twitter Data Analysis Dashboard using Power BI

![Dashboard Preview](Images/Dashboard.png)

---

## 📌 Project Overview

This project is an interactive Power BI dashboard developed to analyze Twitter (X) data. It provides insights into tweet performance, user engagement, and trends using interactive charts, KPIs, and filters.

---

## 🎯 Business Objective

The objective of this project is to transform raw Twitter data into meaningful insights that help understand user engagement, tweet performance, and overall activity through interactive visualizations.

---

## 📊 Dashboard Features

- KPI Cards
- Gauge Chart
- Line Chart
- Clustered Bar Chart
- Clustered Column Chart
- Pie Chart
- Interactive Slicers
- Dynamic Filtering

---

## 🛠 Tools & Technologies

- Power BI Desktop
- Power Query
- DAX
- Microsoft Excel / CSV

## 📈 Dashboard Insights

- Monitors Twitter engagement using KPI cards.
- Visualizes trends through line charts.
- Compares metrics using bar and column charts.
- Shows data distribution using a pie chart.
- Allows interactive filtering with slicers.
- Provides an easy-to-understand dashboard for data exploration.

3. Refresh the data if necessary.
4. Explore the dashboard using filters and slicers.
